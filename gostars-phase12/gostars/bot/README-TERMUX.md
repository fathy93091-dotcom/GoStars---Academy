# تشغيل بوت GoStars على Termux (خطوة بخطوة)

## قبل البدء
- هاتف أندرويد يبقى **شغّالاً ومتصلاً بالإنترنت** ومعه شريحة/حساب واتساب الأكاديمية (يُفضّل هاتف مخصص، وحساب مخصص للأكاديمية وليس حسابك الشخصي).
- ثبّت **Termux** من F-Droid (نسخة Google Play قديمة ولا تعمل).
- شغّلت `010_bot.sql` في Supabase، وضبطت متغيرات Cloudflare (القسم 1).

## 1) متغيرات Cloudflare (مرة واحدة)
في Cloudflare Pages ← مشروعك ← Settings ← Variables and Secrets، أضف (كـ Secret):
- `BOT_SECRET` = نص عشوائي طويل (32 حرفاً فأكثر). ولّده مثلاً بالأمر `openssl rand -hex 24` على أي جهاز.
- (`SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` موجودتان من المراحل السابقة.)
ثم أعد نشر الموقع ليلتقط المتغيرات.

## 2) تجهيز Termux
```
pkg update -y && pkg upgrade -y
pkg install -y nodejs git termux-api
termux-wake-lock
```
وفي إعدادات أندرويد ← التطبيقات ← Termux ← البطارية: اختر «غير مقيّد» (Unrestricted) حتى لا يقتله النظام.

## 3) نقل البوت
انسخ مجلد `bot/` من المستودع الخاص (git clone) أو انقله من ملف الـ zip إلى Termux، ثم:
```
cd bot
npm install
cp .env.example .env
nano .env      # ضع API_URL (رابط موقعك + /api/bot) و BOT_SECRET
```
إن كان الهاتف نفسه هو الذي عليه واتساب الأكاديمية فلن تستطيع مسح QR من نفس الهاتف؛ فعِّل في `.env` السطر `PAIR_PHONE=20...` (رقم الحساب بمفتاح الدولة بلا +) وسيطبع البوت **رمزاً من 8 خانات**: واتساب ← الأجهزة المرتبطة ← ربط جهاز ← «الربط باستخدام رقم الهاتف» وأدخل الرمز.

## 4) التشغيل
```
npm start
```
ستظهر «✅ واتساب متصل» ثم «بوت GoStars يعمل». للتشغيل في الخلفية بعد إغلاق الشاشة:
```
pkg install -y tmux
tmux new -s bot       # ثم npm start ، ثم Ctrl+B ثم D للخروج مع بقاء البوت
tmux attach -t bot    # للعودة
```
بعد إعادة تشغيل الهاتف: افتح Termux وكرر `tmux new -s bot` و`npm start`.

## 5) اختبار القبول
1. من لوحة المعلم احفظ تقريراً لطالب مربوط برقم ولي أمر صحيح.
2. انتظر دقيقة تقريباً (مهلة 60 ثانية لتعديلات المعلم السريعة + دورة السحب).
3. تصل الرسالة لولي الأمر، وتتحول حالة التقرير في `/admin/reports` إلى «أُرسل». ويظهر فوق القائمة «البوت متصل ويعمل».

## أعطال شائعة
| الظاهرة | السبب والحل |
|---|---|
| «سرّ البوت غير صحيح» | `BOT_SECRET` في `.env` يختلف عن Cloudflare (أو لم تُعد نشر الموقع). |
| التقرير «فشل: لا يوجد رقم لولي الأمر» | أضف رقم ولي الأمر من `/admin/students/…` ثم «إعادة المحاولة» في متابعة التقارير. |
| «رقم بلا مفتاح الدولة» | الأرقام المصرية 01xxxxxxxxx تُقبل؛ غيرها احفظه بصيغة +966… أو +971… |
| «الرقم غير مسجّل في واتساب» | الرقم خاطئ أو ليس عليه واتساب. صحّحه ثم «إعادة المحاولة». |
| ظهر «تم تسجيل الخروج من الجهاز» | احذف مجلد `auth` وأعد الربط. |
| «البوت غير متصل منذ N دقيقة» في لوحة الإدارة | Termux مغلق أو الهاتف بلا إنترنت أو قُتلت العملية: افتح Termux وشغّله. |

## تنبيه مهم عن الحظر
البوت يستخدم مكتبة غير رسمية (Baileys) تحاكي «واتساب ويب»، وهذا **مخالف لشروط واتساب** وقد يؤدي لحظر الرقم. خفّفنا الخطر: لا يرسل إلا لمن لهم رقم مسجّل، بفاصل عشوائي 5–12 ثانية بين الرسائل، وبحد 5 رسائل لكل دورة، ولا يرسل رسائل ترويجية. استخدم رقماً مخصصاً للأكاديمية، وأخبر أولياء الأمور بحفظ الرقم، والبديل الرسمي (WhatsApp Business API) مدفوع.
