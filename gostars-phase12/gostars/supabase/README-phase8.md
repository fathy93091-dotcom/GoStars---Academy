# المرحلة 8 — لوحة المدير والمشرف

## الدخول (مخفي بالكامل)
- لا يوجد أي رابط أو نص في الموقع يشير للوحة الإدارة. تُفتح بكتابة **`/admin`** بعد رابط الموقع فقط.
- المدير والمشرف يدخلان من `/admin` فقط. إن حاولا الدخول من `/login` تظهر رسالة «بيانات الدخول غير صحيحة».
- من يفتح `/admin` بحساب معلم أو ولي أمر يرى صفحة 404 عادية.
- كود اللوحة يُحمَّل عند فتح `/admin` فقط، ولا ينزل مع الموقع العام.
- تنبيه: إخفاء الرابط يقلل الظهور فقط. الحماية الحقيقية في قاعدة البيانات (RLS) والمصادقة الثنائية.

## ما فيها
| القسم | المسار | الصلاحية |
|---|---|---|
| الرئيسية (بطاقات حية) | `/admin` | الكل (البطاقات حسب الصلاحية) |
| المستخدمون | `/admin/users` | manage_users |
| الطلاب: إضافة، تعديل، بيانات الاتصال، ربط ولي الأمر، الإسناد | `/admin/students` | manage_students (الإسناد: manage_groups) |
| المجموعات: إنشاء، تغيير المعلم، رابط واتساب، الأعضاء | `/admin/groups` | manage_groups |
| المواد (إضافة/تعديل/تعطيل) | `/admin/subjects` | manage_groups |
| الباقات | `/admin/packages` | manage_students |
| المالية | `/admin/finance` | manage_finance |
| متابعة التقارير (قراءة فقط، حالة الإرسال والمرفقات) | `/admin/reports` | follow_reports |
| متابعة المعلمين (حصص مضت دون تقرير…) | `/admin/teachers` | follow_teachers |
| سجل العمليات | `/admin/audit` | المدير فقط |
| الأمان: التحقق بخطوتين وكلمة المرور | `/admin/security` | المدير والمشرف |

## سجل العمليات
- يسجّل كل إضافة/تعديل/حذف حساس (المواد، المعلمون وأسعارهم، الطلاب، الإسناد، المجموعات، المدفوعات، الباقات، الصلاحيات، إنشاء الحسابات وإيقافها) باسم المنفّذ ووقته.
- للقراءة فقط: لا يُعدَّل ولا يُحذف حتى من الخادم. لا يقرؤه إلا المدير.
- أرقام الهواتف وروابط واتساب لا تُخزَّن فيه (يُسجَّل أنها تغيّرت فقط). بيانات الحصص والطلاب **الشخصيين** لا تدخله.

## التحقق بخطوتين (TOTP)
- يفعّله المدير/المشرف من `/admin/security` بتطبيق مصادقة.
- **تفرضه قاعدة البيانات نفسها**: من فعّله لا تعمل صلاحياته إلا بعد إدخال الرمز، حتى لو استدعى الواجهة البرمجية مباشرة.
- إن فُقد الهاتف: من لوحة Supabase ← Authentication ← Users ← الحساب ← حذف عامل التحقق.
- لتفعيله تأكد أن MFA (TOTP) مفعّل في Supabase: Authentication ← Sign In / Providers ← Multi-Factor (مجاني).

## تغيير معلم المجموعة
ينقل تلقائياً الأعضاء النشطين والحصص القادمة للمعلم الجديد، وتبقى الحصص المنتهية باسم معلمها السابق (حفظاً للأجور).

## في Supabase
1. **نسخة احتياطية أولاً.**
2. نفّذ `007_admin_panel.sql` بعد 006. يعيد تعريف دوال الصلاحيات لتشمل التحقق بخطوتين، فإن أعدت تنفيذ 001 أو 003 يوماً فأعد تنفيذ 007 بعدهما.
3. انشر الكود (دالة `admin-users` تسجّل الآن في سجل العمليات).

## ما لم يدخل (قراره في المرحلة 9)
تعديل نصوص الموقع وصوره وإخفاء الصفحات والإعلانات بلا كود (CMS).

## الاختبارات
قاعدة البيانات 232، أمان المسارات 76، لوحة الإدارة 63، المعلم 44+، المالية 30، دوال الخادم، الذكاء الاصطناعي. كلها ناجحة محلياً. **لم تُجرَّب على Supabase الحقيقي بعد.**
